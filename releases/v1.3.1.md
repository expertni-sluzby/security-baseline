Vydání přes GitHub Actions
Vydání security-baseline teď probíhá na GitHubu. PR, které přidá soubor `releases/vX.Y.Z.md` (první řádek název, zbytek poznámky), po merge vydá vX.Y.Z, jakmile na tom commitu projde self-test, a posune na něj hlavní tag `v1`. Dělá to workflow `release.yml` s GitHub App `expertni-sluzby-baseline-release`, která jediná (kromě adminů) smí vytvářet tagy vydání a posouvat `v1`. Její klíč je v prostředí `release`, dostupném jen z main.

Návrat k předchozímu vydání: Actions → release → Run workflow s `rollback: x.y.z`.

Pro konzumenty se nic nemění, `baseline.yml` je stejný jako ve v1.3.0. Tohle vydání ověřuje celý postup. (#21, #22)
